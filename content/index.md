# 🌍 База кампании — Наэнтар

> [!abstract] О базе
> Знания по нашей новой D&D-кампании в мире **[[Наэнтар|Наэнтара]]**. Пока база собрана из одного источника — «Путеводителя по игровому миру» от ГМ: это общие сведения о мире, которые может знать любой персонаж. С первой разобранной сессии сюда пойдут пересказы игр, партия, NPC и места, где побывала группа. Спорные факты помечаются `(?)` и блоками `[!warning] Требует подтверждения`. Канон-имена — в [[_Глоссарий]], история правок базы — в [[Changelog]].

- [[Зарис]] — королевство торговцев, выросшее из разбойничьих застав; столица [[Сарван]]
- [[Гайбел]] — Соединённое королевство трёх провинций под двумя диархами
- [[Гвилар]] — теократия в заснеженной горной долине, только люди
- [[Ак'адарский халифат]] — пустыня на востоке, пять иклимов; столица [[Закира]]
